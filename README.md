# int2025_t — целочисленный тип фиксированной длины

Пользовательский тип для представления знакового целого числа фиксированной разрядности, реализованный без использования стандартных контейнеров и `std::bitset`.

- Размер типа: не более 254 байт.
- Диапазон значений: $[-2^{2024},\ 2^{2024} - 1]$.
- Переполнение обрабатывается по правилу `wrap around` (`MAX + 1 == MIN`, `MIN - 1 == MAX`), а не как UB.

## Возможности

- Конструирование из `int32_t`.
- Конструирование из строки (десятичное представление числа).
- Арифметические операции: сложение, вычитание, умножение, деление.
- Операторы сравнения на равенство/неравенство.
- Вывод значения в поток (`operator<<`), не обязательно в десятичной системе счисления.

## Структура проекта

```
.
├── bin/     — консольное приложение для ручной проверки
├── lib/     — реализация типа (number.h, number.cpp)
└── tests/   — набор тестов на GoogleTest
```

Структура и состав файлов фиксированы и не подлежат изменению.

## Сборка и тесты

Запуск тестов:

```
cmake --build build --target number_tests && build/tests/number_tests
```

Запуск демонстрационного консольного приложения:

```
cmake --build build --target labwork2 && build/bin/labwork2
```

## Пример использования

```cpp
#include "number.h"

int2025_t a = int2025_t(42);
int2025_t b = int2025_t("123456789");

int2025_t sum = a + b;
int2025_t diff = a - b;
int2025_t prod = a * b;
int2025_t quot = b / a;

if (a == b) {
    // ...
}

std::cout << sum << std::endl;
```
